## Reconciliation Notes

- **Assets confirmed in the onboarding packet but not previously known:** the full domain controller pair (`ad-dc-01/02`), `file-srv-01`, `print-srv-01`, `ws-srv-01`, all network hardware (FortiGate, Cisco switches, Ubiquiti APs, the Westside Netgear router), the infusion pump fleet, the CT scanner, the nurse call system, and the HID badge system. Several of these (print server EOL, PostgreSQL open to the full `/16`, backup NAS sharing production's rack/network, Westside's total absence of a firewall) are now material findings that materially change the Gap Analysis (Task 12) and should be reflected there.
- **Assets referenced in earlier task work that the packet does not explicitly confirm:** the Pharmacy Management System (Incident C) has no confirmed hosting server in the IT asset export — this is a genuine gap in MedDefense's own documentation, not just this assessment's visibility, and should be flagged to Sarah Park directly rather than assumed.
- **Assets a network scan would likely surface but this registry cannot confirm:** the unconfirmed second Westside server (A-013), any unsanctioned departmental cloud services beyond O365 (Marcus suspected these but never inventoried them), and a current, accurate endpoint count (the existing figures are drawn from an 8-month-old Active Directory report).
- **Discrepancy carried over from Task 0:** the server room's physical location (basement per the HR guide vs. ground floor per the walk-through) remains unresolved and affects how Asset A-024 should be scoped.
